# HOJ 教学管理中心

访问 [账号登录](http://127.0.0.1:3100/management/login)，使用 `admin` 登录，再进入 [教学工作台](http://127.0.0.1:3100/management/home)。`admin` 具备教师功能及超级管理员权限，登录、退出均在教学平台内完成，HOJ 与管理中心共用账号身份。账号密码保存在本地 `.local/admin-account.json`（0600，不进 Git）；启动不会重置密码。体验身份快捷登录已关闭。

采用参考 Grader 的教学管理模块，提供课程、教师、助教、学生名单、账号与批量导入、作业发布与提交、缺交名单、成绩录入、统计和 CSV/XLSX 导出。编程题使用 HOJ 题库与判题。

PDF/Word 转换、文档批注、ZIP 在线批阅及相关前端依赖已移除，部署不再运行 Gotenberg。附件仍可正常上传与下载，提交详情直接录入成绩。旧参考功能源文件仅保存在本地 `.local/removed-document-features/`，不参与构建。

## 本地运行

首次初始化本地管理员可执行 `python3 deploy/local/create-admin.py`；该命令仅操作本仓库隔离的 HUSTOJ 容器，重复运行不重置已创建的密码。

在仓库根目录运行：

```sh
python3 deploy/local/manage.py start
python3 deploy/local/manage.py status
python3 deploy/local/manage.py stop
```

需要 Docker/Colima、Node.js、Corepack 和 Rust。所有服务端口绑定 `127.0.0.1`，两个数据库及文件存储使用独立本地卷。

| 服务 | 本地地址 |
| --- | --- |
| 主站及教学管理中心 | http://127.0.0.1:3100 |
| HOJ API | http://127.0.0.1:8100 |
| 教学管理 API | http://127.0.0.1:8101 |
| 教学管理前端 | http://127.0.0.1:3101/management/ |
| 内部账号适配接口 | `127.0.0.1:8080`，原生网页已关闭 |
| 私有文件存储 / 控制台 | http://127.0.0.1:9002 / http://127.0.0.1:9003 |

管理中心 API 使用 `/management-api/`，前端使用 `/management/`。数据库、存储及验证管理员随机密码保存在 `.local/management-secrets.json`，权限为 `0600`，不进 Git。日常在统一登录表单使用 `admin` 账号。

## 功能与权限

| 功能 | 内容 |
| --- | --- |
| 教学工作台 | 我的课程、近期作业与开放作业计数、常用教学管理入口 |
| 课程及名单 | 学年/学期、负责教师、助教、学生、课程过滤与增删改 |
| 用户管理 | 师生查找、创建与停用、密码管理、CSV/XLSX 批量导入及模板 |
| 作业管理 | 草稿、发布、开放与截止时间、附件类型与大小限制、满分、成绩可见性 |
| 提交管理 | 私有存储签名上传、重交、已交与缺交名单、原文件及批量下载 |
| 成绩管理 | 直接评分、已评与未评、课程分数表、分布与统计、CSV/XLSX 导出 |
| 管理后台 | 公告、审计动作、文件清理与存储控制台入口 |

HOJ 导入账号通过原 HOJ 身份登录，每次管理 API 请求回源校验身份，不使用独立本地密码登录。账号切换及退出同步清除旧会话，写入请求受 CSRF 保护。管理中心新建的独立账号也可使用同一表单；已关联 HOJ 的账号必须通过原有密码校验，不能以管理中心密码绕过。

首页“Excel 导入名单”打开名单上传窗口，提供两列 XLSX 模板（学号、姓名）；学号列预设为文本。默认创建学生，也兼容旧“用户名、姓名、角色”三列。工作表名不限，有多个名单表时需明确选择；上传后先预览，格式错误显示行号；相同重复行合并，信息冲突则停止。已有账号默认忽略并保留密码、角色，覆盖需要单独确认。导入账号后，在课程与名单管理中将学生加入课程。

“同步已有 HOJ 课程”由超级管理员同步活跃 HOJ 教学班，用当前 HOJ 名单替换关联课程成员，并保留作业、提交和成绩。它不读取 Excel。使用共享平台账号新建课程时会关联同一编程教学班；在管理中心保存学生与助教名单时会同步至该关联班级。课程页直接显示已发布的编程实验、提交人数以及编程成绩导出入口。

按最新联合测试流程，教师可以创建学生账号和自己的班级；新教师账号仍由超级管理员创建。课程删除、课程配置、教师名单、账号角色变更、停用及他人密码重置由超级管理员维护。任课教师可维护本人课程的学生、助教、作业和成绩，其他课程只读，不能将自己加入其他教师的班级。教师批量导入学生时不能覆盖已有账号。HOJ 课程同步由超级管理员执行。助教只具备指定课程教学权限。

编程实验按已 AC 计分题的权重占比折算为 100 分；教师可在草稿和已发布题单中设置每题权重。权重为 0 或选做题不计分，旧题单默认等权，重复提交不会重复加分。修改权重后，已有提交的成绩立即重新计算。班级成绩包含未提交学生，并支持带 UTF-8 BOM 的 CSV 导出。成绩导出接口与教师查看学生源码接口均校验班级权限，学生只能查看本人源码。

会议要求、部署候选与尚未完成的功能见 [实施清单](../deploy/local/meeting-requirements.md)。

## 演示与验证

“程序设计基础 · 01班”包含第一周练习、课程项目阶段检查、期末项目提交材料三份演示作业。体验学生已提交 TXT 或 ZIP 材料并录入 95 分，其他学生的缺交状态可查看。

`deploy/local/management-demo.py` 使用合成材料生成示例，重复运行不新建同名作业。原文档演示作业已改为上述教学管理示例。

```sh
python3 deploy/local/management-smoke.py
python3 deploy/local/management-teaching-smoke.py
python3 deploy/local/management-permissions-smoke.py
```

前者验证 HOJ 身份、CSRF、课程导入、学生和助教权限、切换及退出；后者验证成绩录入（含零分）、提交状态、导出数据、课程统计及已移除接口返回 404。前端执行类型检查与生产构建，后端执行 Rust 构建。浏览器验证提交详情和实际 Excel 导出。

早期会议权限检查曾通过 67 项。2026-10-03 的联合测试按最新教师开班权限，在备份并清空旧业务数据后，通过真实页面完成管理员建教师、教师建学生与班级、加入名单、编写与发布 C++ 题目、学生提交、教师看源码和下载成绩。当前数据可用 `python3 deploy/local/joint-workflow-smoke.py` 检查，39 项全部通过；编程后端 121 项测试、两套前端类型检查与生产构建通过。详情见 `../deploy/local/joint-test-report.md`。

参考 API 探针仍在 `backend/test/probe.ts`，其原有“教师可管理任意用户及课程”断言不适用于新的权限策略，应使用上述本地检查验收。旧 `grading-probe.ts` 针对已移除功能，也不适用于精简版。测试产物与日志保存在 `.local/`。体验身份检查需要专门启用开发登录，仅用于回归测试。日常环境保持 `COURSE_DEV_LOGIN=0`。学校外部 SSO、自动建议提取服务及 Grafana 未配置；教学管理与手动评分不依赖它们。

名单导入格式检查：在 `teacher-management/frontend` 执行 `node --experimental-strip-types --test scripts/roster-import.test.ts`，13 项通过，覆盖两列和旧三列、文本及格式化数字的前导零、UTF-8 CSV、重复冲突、空值行号、多工作表和实际下载模板。浏览器验证上传预览、错误提示与已有账号忽略后的持续反馈；未创建额外体验账号。
