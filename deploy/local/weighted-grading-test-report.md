验证结果：66 项接口与真实判题检查通过，123 项 Rust 库检查、32 项前端测试通过，后端编译与 Next 生产构建通过。包括非法/负数/超范围/全零/缺漏/重复/跨题单权重拒绝、失败事务不改变已有权重、学生无权修改、复制及 YAML 公开导出保留权重、公开导出不含隐藏测试、原题单 10 成绩仍为 100 / 0 / 0，以及 CSV 中满分、部分得分、缺交状态一致。

浏览器核验：教师草稿权重发布；已发布题单全零时显示提示并禁用保存；保存权重后显示成功提示；学生查看自动成绩与比例；教师实际下载并逐行核对 CSV。

数据记录：`.local/weighted-grading-result.json`；下载副本：`.local/weighted-grading-student-grades.csv`。回放脚本 `deploy/local/weighted-grading-smoke.py` 需要专用题单没有现存提交；它会产生真实提交并修改再恢复专用题单权重，不适用于正式教学数据。第一次测试数据备份保存在 `.local/backups/weighted-grading-first-run.sql`。
