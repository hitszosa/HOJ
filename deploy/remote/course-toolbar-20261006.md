# 课程页统一操作栏（2026-10-06）

管理课程详情页此前有两组操作按钮，以及右下角的新建作业浮动按钮。现在将操作集中到标题下方同一条可换行操作栏：布置作业、名单与课程设置（教师显示管理名单）、成绩与导出、管理员删除课程。作业题单标题下方只放作业内容，不再放第二组操作。

“布置作业”统一进入当前课程实际关联的 `/programming/offerings/:offeringId` 工作区，从那里选择题单、从公共题库选题、自编或导入。移除课程详情的浮动加号、占位留白和引导点击右下角的文案。没有文件作业时隐藏文件作业统计；存在旧文件作业时在同一操作栏提供“文件作业成绩”，保留其原有功能。

教学班关联、教师/助教/学生/管理员权限和 active 状态门槛未变。创建、成绩地址由同一个桥接组件加载真实课程关联后通过插槽提供；不混用管理课程 ID 与编程教学班 ID。管理员删除继续使用上一轮物理删除接口及明确的提交/成绩删除确认。

本机 Vue 类型检查及生产构建通过，并在实际联测教师课程页验证操作栏三个按钮高度相同、无浮动加号，点击“布置作业”到达对应题单工作区。布局使用 flex-wrap，窄屏自然换行。服务器仅重建和替换管理前端镜像；API、数据库、课程数据和判题服务不修改。服务器验收检查现有课程/班级映射、作业工作区、题库、成绩地址及部署静态资源摘要，不创建或发布题单。

本机证据在 `.local/course-toolbar/`；服务器记录在 `/opt/hoj/qa-fixes/course-toolbar-*`。部署前保留管理页面镜像与源文件备份，验收失败恢复旧镜像。
