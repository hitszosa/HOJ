# 班级学生题单成绩及提交权限（2026-10-06）

教师不再有独立评测记录入口，教师直接访问旧 /judging 地址返回课程列表。学生端入口改为“我的提交”，界面不提供全站或其他用户筛选。共享导航在教学管理和题库两端按实际角色执行，教师兼学生账号也不出现独立入口。

GET /api/status 在未指定班级时无论身份只返回本人记录；在班级内只有本班教师可以查看班级提交，学生即使传入 only_mine=false、其他 user_id 也只能看到本人。列表及 total 使用同一权限过滤。代码接口只允许本人、管理员或提交所属班级教师，任课身份不再授权查看该学生其他班或自由练习的代码。

班级页面作业题单下新增可按学号和姓名查找的学生名单，点击学生在本页面展开每个已发布题单的每题最好成绩、结果、加权得分、提交次数及对应代码。GET /api/offerings/{oid}/students/{uid}/progress 先检查本班教师权限及学生在本班成员关系，再读取本班提交。

沿用现有 AC 计分：单题 AC 为 100，未通过为 0，未提交及仅有等待判题记录显示未确定成绩。优先选择 AC；同分选择较新的已完成提交，只有没有已完成结果时才选择待判提交。最好结果与代码共用同一 submission_id。题单总分按必做题权重归一化，与现有成绩和导出接口一致。所有题单结果一次查询，源代码点击时才加载，不逐题拉取代码。

本机验证：前端 51 项测试、后端 HTTP 9 项测试及待判成绩单元测试通过；类型检查、Next 生产构建和管理端 Vue 生产构建通过。52 个实际 API 请求验证先 AC 后 WA 保留 AC、对应代码一致、30/70 权重与班级成绩一致、多题单、未提交、学生改参数及直取别人代码失败、其他班教师成绩和代码访问失败。真实判题和浏览器班级名单、每题最好成绩、代码弹窗已验证。临时课程、题单、题目、提交和代码已实际删除，原课程和个人题库不变。

服务器更新 api、web、management-web 镜像为 student-progress-20261006，无数据库结构迁移。部署前镜像备份 before-student-progress-时间戳，源码备份及补丁在 backups，清单及验证结果在 qa-fixes，日志在 build-logs。服务器复查只读，不创建正式数据。
