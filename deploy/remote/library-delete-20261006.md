# 已发布个人题单删除与课程删除同步（2026-10-06）

此前个人题库删除接口把 published 状态一律拒绝；管理侧删除课程又没有关闭关联的编程教学班，导致已删课程仍留在发布目标和编程域中。

个人题库删除现在允许题单所有者或管理员删除草稿及已发布来源。删除来源时解除已布置批次的 authoring_key，不删除批次、题目、隐藏测试、学生提交或成绩。教师不能删除其他教师的个人来源，学生和助教不能调用该操作。该操作不再受原教学班 archived 写入限制，已删除班级下的个人题单也可以清理。前端确认提示说明已布置作业与评测记录会保留。

管理课程删除在原有管理员鉴权和课程锁内，先调用受信 Origin 与原生管理员会话保护的课程归档接口：关联教学班 archived、题单批次 closed、成员 dropped。调用失败会取消管理侧删除。重复归档幂等；MGMT 编码与课程 ID 不一致则拒绝。编程侧导入上下文与个人题库发布目标只显示 active 教学班；归档班级的教师仍可读取历史成绩。同步名单与发布事务在提交前锁定教学班并核验 active，防止删除课程与更新、发布竞争后恢复名单或作业。

个人来源删除与单班、多班发布使用同一命名锁，多班发布在锁内重新读取来源，发布事务再次核验来源存在。删除后再次发布返回 404。两个服务之间没有分布式事务：原生归档成功后若管理数据库提交异常，可重试管理删除，归档幂等。
