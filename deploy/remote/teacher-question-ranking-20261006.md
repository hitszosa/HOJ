# 教师每题排行榜

作业详情新增默认收起的“每题排行榜（教师）”，可切换题目、按学号/姓名搜索、20/50 人分页，查看最好成绩对应的提交代码。

接口：`GET /api/batches/{bid}/problems/{pid}/teacher-ranking`，支持 `page`、`page_size`、`search`。先检查本班教师权限，再验证题目属于本次作业。学生、助教和其他班教师不能读取；超级管理员沿用既有班级教师访问权限。

按该学生在本班、本次作业、本题的最好已提交结果计分：AC 100，其余完成结果 0；同分并列（密集排名），未提交或仅等待判题不排名。AC 优先，同分取较新的提交，和学生详情一致。搜索不重新排名，只筛选已经排好名次的全班名单。题库练习、其他作业和其他班提交不计入。

无数据库结构变更。旧的全站排行接口仍为 404。发布镜像 `hoj-api:question-ranking-20261006` 和 `hoj-web:question-ranking-20261006`。更新前备份源代码及镜像到服务器 backups 和 before-question-ranking 时间戳标签。

验证资料：`.local/question-ranking/`，含后端 HTTP 测试、前端教师/学生/助教渲染及迟到请求测试、类型检查与构建、服务器实测和实际删除测试数据的记录。
