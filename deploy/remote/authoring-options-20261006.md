# 统一出题入口（2026-10-06）

题库和我的题单统一使用“去出题”。独立 AI 出题按钮、标签页和生成题单页已移除；旧 `tab=ai` 链接进入统一出题流程。

为题单命名后进入同一个编辑器。每题默认“自己编写”，可切换“AI 帮我搭框架”，输入教学要求并预览生成结果。只有点击“使用这个框架”才替换当前题目的题面、样例、隐藏测试及知识点，保留当前题目标识和计分权重，不影响其他题目。采用后可继续修改，保存及布置作业仍需教师主动操作。

新增 `POST /api/teacher/library/framework`：仅教师和管理员可用，教学要求不能为空，最多 500 字符，沿用现有 AI 配置。该请求不创建题单、不写数据库、不发布作业。课程中已发布作业的修订编辑器继续使用现有修改及重判流程。

验证：前端 48 项测试、类型检查和生产构建通过；后端 HTTP 9 项测试及生产构建通过。新增测试验证预览不覆盖原输入、主动采用保留权重及其他题目、隐藏测试保存、AI 失败仍可手工保存、课程修订不出现新出题选项。真实 API 核验匿名 401、学生 403（本机）、空要求 422，未新增个人题单。浏览器验证了同页切换、输入要求、返回我的题单及统一入口。临时浏览器验证题单已实际删除。

本轮使用模拟 AI 响应验证生成后的编辑流程，未调用真实模型，未修改 AI 服务配置。服务器 API 和 Web 使用 `authoring-options-20261006` 镜像；其他服务保持现有版本。源码清单、前后源码备份和构建日志保存在服务器 `qa-fixes`、`backups`、`build-logs` 目录；可使用 `authoring-options-deploy-stamp` 对应的 `before-authoring-options-时间戳` 镜像回滚。
