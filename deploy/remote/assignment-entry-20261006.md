# 统一课程新建作业（2026-10-06）

课程详情右下角「新建作业」直接进入该课程关联的 `/programming/offerings/:offeringId` 题单工作区，可以选择已有题单、自编或导入，随后编辑权重、截止与语言设置并发布。移除课程页打开旧文件作业创建弹窗的函数和入口；已有文件作业保留修改、查看和成绩等操作。

作业区域统一标为「作业题单」，撤掉重复的「新建编程题单」按钮。「从题库选题」仍携带当前教学班 oid，学生从课程页进入已发布题单。

浮动按钮的目标由实际课程关联与教学班状态生成，不混用管理课程 ID 和编程教学班 ID。只有具备当前管理课程教师权限、关联教学班教师角色且教学班 active 时开放新建。学生、助教、只读课程不获得出题入口。加载失败或缺少关联显示错误及重试，不回退到旧文件作业表单。新建课程 API 已在同一流程同步课程关联，该逻辑未改动。

Vue 类型检查和生产构建通过；编译产物确认包含统一入口，服务器通过动态课程关联验证题单工作区、草稿读取、题库与返回课程地址，并验证部署资源摘要。本轮仅更新管理页面镜像，保留上一轮管理员删除按钮；不改数据库、API 或判题服务，不调用 AI，不创建或发布测试作业。本机内置浏览器导航被客户端阻止，因此本轮未声称完成浏览器点击或实际发布验收。

构建、摘要与回归证据位于本机 `.local/assignment-entry/` 和服务器 `/opt/hoj/qa-fixes/assignment-entry-*20261006*`，镜像 `hoj-management-web:assignment-entry-20261006`。部署前备份源文件及旧管理页面镜像，验收失败会恢复旧镜像。
