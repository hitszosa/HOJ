# 课程入口统一（2026-10-05）

课程入口只保留 `/management/courses`。创建课程、管理名单和普通作业都在教学管理中操作；同一课程页直接列出编程实验，并提供新建编程题单、题库选题及编程成绩导出。编程题库保留题目、题单与选题功能。

React 端的独立 CourseList、Course、ClassManagement 组件及开班表单已删除。旧 `/teacher`、`/student` 和历史课程首页跳转到教学管理课程列表；旧课程详情和名单 URL 在服务端读取当前用户有权限访问的 `/api/hoj/links`，按 `offering_id → course_id` 跳回对应管理课程。未登录跳转登录，未授权/不存在的关联返回 404。管理课程与编程教学班 ID 不混用。

编程题单编辑、批次详情、答题和成绩页保留现有判题业务，增加返回管理课程链接，平台模块高亮教学管理，不再展示独立编程课程导航。教师选题和出题按钮同时检查当前管理课程权限与编程教学班角色，助教、学生和归档课程不显示任课教师写入口。

服务器已有编程教学班 3、4 分别关联管理课程 5、6；本机教学班 2 关联管理课程 12。不需要导入、迁移或重建，课程、名单、提交及成绩数据沿用。
