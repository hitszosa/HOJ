# HUSTOJ 教学平台本机验收

2026-09-19。主体为 HUSTOJ 改造版，教学界面与服务半独立，CodeMind 仅参考。

## 入口与测试顺序

- 教学平台：http://127.0.0.1:3100/
- HUSTOJ 原生入口：http://127.0.0.1:8080/course.php
- 使用同一主机名，不混用 localhost 和 127.0.0.1。原生账号登录后可从 HUSTOJ 导航的“教学工作台”进入；已有账号只看到自己有选课/任课关系的课程。
- 体验完整功能可退出当前账号，在教学平台展开默认折叠的“本地测试工具”，选择学生/教师身份，进入 PILOT1007 试点课程。开发入口不用于正式部署。
- 学生：当前课程 → 批次题单 → 题目 → 提交代码 → 判题 → 分级学习反馈；历史课程只读。
- 教师：教学工作台 → 管理课程 → 自编或导入 YAML/JSON/FPS 题单 → 审核样例与隐藏测试 → 发布 → 查看班级学情；归档班禁止写入。
- 界面：仅保留统一蓝白风格，无风格选择器。登录后服务端自动分流到 `/student` 或 `/teacher`，首页、导航、课程/批次/题目详情路由分开。学生看自己的练习；教师/助教只读预览题目，班级统计进入学情页。
- HOA：课程资源链接、来源记录、选择性公开题单下载；隐藏测试不公开导出，read_only 来源拒绝公开导出。
